# ManboHakimi-Harp

《三角洲行动》口风琴视觉练习辅助工具。浮窗显示乐谱、琴键和演奏进度，由玩家自己按键演奏。程序不模拟键鼠输入、不读取游戏画面或内存、不注入游戏进程；数据保存在本机。

> 第三方浮窗与游戏反作弊系统的兼容性无法保证。请先在训练场测试，并遵守游戏服务条款；如官方明确禁止，请停止使用。

## 下载与版本

- [下载最新正式版](https://github.com/tianyiyao/ManboHakimi-Harp/releases/latest)：Windows 10/11 单文件 EXE，无需安装 Python。目前正式版为 **v0.15.0**。
- 仓库源码包含 **v0.15.3 测试候选版**的修复、快捷键调整和浮窗按钮，尚未发布对应的正式版 EXE。构建与验收状态见 [交付检查清单](RELEASE_CHECKLIST.md)。

下载 EXE 后，放在可写目录并双击运行。首次启动请阅读风险提示；右下角托盘图标可管理浮窗和退出程序。设置与用户曲目保存在本机 `config/`、`scores/`。遇到问题可查看 `config/harpguide.log`。

## 基本操作

1. 打开游戏口风琴，在浮窗左侧选择曲目。
2. 对照浮窗提示，手动按 `Z X C V B N M ,` 演奏。
3. 用浮窗按钮开始/暂停、重置、切换悬浮球或隐藏浮窗；也可使用下表快捷键。

| 快捷键 | 功能 |
| --- | --- |
| 小键盘 7 / 8 | 开始或暂停 / 重置 |
| 小键盘 9 / + | 显示或隐藏浮窗 / 切换悬浮球 |
| 小键盘 1 / 2 / 3 | 降调 / 自然 / 升调 |
| 小键盘 0 | 自动变调开关 |
| Ctrl+Shift+A / B | 设置 A、B 循环点 |
| Ctrl+Shift+T / C / E | 鼠标穿透 / 琴键校准 / 乐谱编辑器 |
| Ctrl+Shift+Q | 退出 |

使用小键盘数字时请开启 Num Lock。程序不再占用游戏的 F1–F4。更多功能、曲谱编辑和故障排查见 [使用说明](USER_GUIDE.md)。

## 从源码运行

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

运行 `build.bat` 可执行检查并构建 Windows EXE；产物位于 `dist/`，不会提交到源码仓库。改动记录见 [CHANGELOG.md](CHANGELOG.md)。
