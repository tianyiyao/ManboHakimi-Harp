# ManboHakimi-Harp 体验版使用说明

适用版本：Windows 测试候选版 0.15.3。非《三角洲行动》官方产品。

## 1. 启动

1. 如果以前运行过旧版，先从系统托盘完全退出旧版。
2. 双击 `ManboHakimi-Harp.exe`。单文件运行，无需安装 Python。
3. 首次启动阅读风险提示，并按界面要求确认。程序会在 EXE 同级目录保存配置和自建曲目；该目录不可写时改用 `%APPDATA%\ManboHakimi-Harp`。

## 2. 五分钟上手

1. 先进入游戏训练场。把浮窗拖到不挡视线的位置。
2. 鼠标移到浮窗左边缘的“曲目”把手，展开列表并选曲。
3. 点击浮窗的 **开始**。按照提示手动按 `Z X C V B N M ,` 八个键。
4. 点击 **暂停** 可停下，点击 **重置** 回到曲首；设置了 A-B 区间时会回到 A 点。
5. 点击 **悬浮球** 可收起完整浮窗，点击球体恢复；点击 **隐藏** 后，可通过系统托盘或小键盘 9 恢复。

## 3. 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| 小键盘 7 / 8 / 9 / 加号 | 开始暂停 / 重置 / 显示隐藏 / 悬浮球 |
| Ctrl+Shift+C | 进入琴键校准；校准中再次按下保存 |
| Ctrl+Shift+A / B | 标记循环 A 点 / B 点 |
| Ctrl+Shift+T | 切换鼠标穿透 |
| Ctrl+Shift+E | 打开曲谱编辑器，可粘贴简谱 |
| Ctrl+Shift+Q | 退出程序 |

小键盘数字快捷键需要开启 Num Lock。开启鼠标穿透后，鼠标不能点击浮窗按钮；按 Ctrl+Shift+T 关闭穿透即可重新操作。

## 4. 对齐与反馈

- 提示琴键与游戏键位不齐时，按 **Ctrl+Shift+C** 进入校准，拖动提示键与游戏键位重合，再按一次保存。不同分辨率和屏幕缩放有独立档案。
- 可在设置中调整速度、瀑布流提前量、判定偏移、歌词和命中反馈。命中反馈只被动读取按键状态，游戏演奏仍由玩家手动完成。
- 托盘菜单可打开曲目文件夹、刷新曲库、打开编辑器和退出程序。

## 5. 体验反馈

建议记录 Windows 版本、游戏窗口模式、屏幕分辨率与缩放、使用的曲目，以及问题出现前的操作。若程序异常，可附上配置目录里的 `config/harpguide.log`。日志留在本机，不会自动上传。

这是非官方第三方浮窗；游戏对 Overlay 的兼容与规则边界仍需实机验证。请先在训练场测试，并遵守游戏服务条款。此版本为测试候选版，尚未公开发布。
